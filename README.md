# Shadab Khodajoo — Creative Portfolio

A bilingual (English/Persian), responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Live website
After enabling GitHub Pages, the website will be available at:
`https://khodajoo1993-collab.github.io`

## Features
- English and Persian language toggle
- Responsive layout for desktop, tablet and mobile
- RTL layout for Persian
- Filterable project gallery
- Dark luxury visual direction
- No build tools or framework required

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your public contact email.
2. Update Instagram, LinkedIn and GitHub links.
3. Replace the sample project cards with approved images/videos and accurate project descriptions.
4. Review all text and remove any project you do not have permission to show.

## Publish with GitHub Pages
1. Create a public repository named exactly `khodajoo1993-collab.github.io`.
2. Upload all files and folders from this repository root (not the containing ZIP folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish.

## Customize
- `index.html`: page content, project cards and social links.
- `style.css`: colors, typography, spacing and responsive layout.
- `script.js`: translations and project filtering.
